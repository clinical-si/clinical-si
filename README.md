# Clinical-SI

Small, calibrated language models for clinical classification. The model reads, the code decides, and anything it
isn't sure about goes to a person.

**Website:** [clinical-si.com](https://www.clinical-si.com) · **Live demo:** [cce.clinical-si.com](https://cce.clinical-si.com) · **Contact:** brian@clinical-si.com
