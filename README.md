# Clinical-SI

Small, calibrated language models for clinical classification. The model reads, the code decides, and anything it
isn't sure about goes to a person.

**Website:** [clinical-si.com](https://www.clinical-si.com) · **Live demo:** [cce.clinical-si.com](https://cce.clinical-si.com) · **Contact:** brian@clinical-si.com

## Demos

- **[Calibrated Classification Engine, live](https://cce.clinical-si.com):** the same 0.8B model at three stages (off
  the shelf, trained, and with a confidence hand-off) playing a puzzle game side by side, so every move can be checked
  against an expert. [How it works](https://cce.clinical-si.com/how). No patient data.
